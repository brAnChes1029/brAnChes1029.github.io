2026 暑假的團體賽
Aug 29, 2026

前言

可能是因為看到涓涓都會寫團體賽的 blog 所以讓我也有點想寫哈哈哈哈哈。

我想到我以前不是喜歡打團體賽的人。
我覺得團體賽跟別人溝通很麻煩，表現又跟自己打差不多。

又到了團體賽的季節了，明明之前常常打到不開心 ，但我又學不乖想去玩。

所以感謝楊岳蓁和張語珊陪我玩。

比賽

成大賽 初賽

隊名 : 蓁吳語，是睿睿取的 !

為了防作弊的樣子，成大賽要求三位選手要在同地點用一台電腦，而且還要錄影。
因此我們去了…楊岳蓁家 !

先去吃了午餐 : 日日好日，法式吐司好好吃喔。
接下來前往楊岳蓁家，楊岳蓁家超高的，而且很漂亮，整個家都很乾淨又很整齊，像我的房間大概就稍微比較雜亂，楊岳蓁太會整理房間了吧。
我們是在餐廳打的。

我開場先發現 pI 是簽到，所以先簽掉了。順便發現 pA 是 BIT 優化 DP 轉移，先去旁邊想個細節，換張語珊打。
輪流弄了一下後 pA pD 都過了，我又發現 pC 是二分搜，去旁邊想，張語珊認領 pG ( 結果我都沒看那題 )，pH 長得有點像 cake 觸發我的心理陰影所以給楊岳蓁了。
( cake 就是我在 EGOI 噎到然後摔下金牌線的題目 (┬﹏┬) )

不久我開始實作 pC，想說 $3e8$ 兩秒應該可以吧，被楊岳蓁提醒 DP 可以用單調隊列而不是亂砸 zkw，成功壓到 $3e7$ 一次過，團隊合作讚。
換楊岳蓁實作 pH，一次過。

接下來的時間都是張語珊 debug pG，楊岳蓁修 pF ( 最後有過 )，楊岳蓁壓 pE 壓不過，我 pB 負責 WA。

打完之後楊岳蓁媽媽買了點心跟飲料，好好喔 !

收在 rk.7。
這次打完之後，我覺得我們 workflow 好像還滿不錯的 ?

檢討 :

  • 沒看 pG，它其實很簡單
  • 沒好好觀察，亂砸線段樹 ( 雖然 zkw 很好寫啦 )
  • 以為全部 judge 都跟 EGOI 一樣超快

YTP 初賽

隊名 : Luca 好可愛，是我取的哈哈哈

楊岳蓁去北一女考試到 5.，張語珊生病了，有點不妙欸。結果楊岳蓁考完就超快出現在她媽媽的車上然後開始打，但我覺得她暈車了，總之這場是大混亂。

我寫了 Hello 跟簽到 ( 這是不同題 )，然後發現我要做 p1 p4 p7，p4 太麻煩不如做 p7，p7 被卡常超級久，但我函數名字取 Luca 所以可能很棒，最後還是過了。
張語珊某個 DP 卡很久，有點擔心，但最後還是過了 : D
楊岳蓁從頭到尾在寫同一題，但她可能暈車了，我也不是很確定最後有沒有過。

也不清楚最後第幾名，總之很混亂但進決賽了。

不重要小插曲 : 國中的 NPSC

我國中打過 NPSC，國三 ( 2023 ) 打到 rk.8 吧，好像是寫太慢和構造題構出很醜的東西在 debug，我記得很好笑的是封板後還有人給我氣球，這樣計分板就白封了啊。
我那時候拿到 $5$ 個氣球的樣子，雖然沒前六沒拿到錢有點不甘心，但也算沒有遺憾。

喔然後雖然 NPSC 是團體賽，但我都一個人打。

然後 NPSC 就死掉了 !
剛好我高一想說找不到人組隊，沒差。不過他竟然轉生了耶。

NTUCPCPC 初賽

隊名 : 侯欣緯隨便打都世界冠軍，楊岳蓁取的 ( 下次考不考慮取楊岳蓁一模隨便打都破台 )

初賽沒有說要三人同地方，但我想去楊岳蓁家玩，謝謝楊岳蓁讓我去她家玩。

午餐日日好日好吃，然後我還彈到楊岳蓁家的鋼琴，好好玩喔 ! 但我沒有背譜所以彈得有點爛。

開場我先做了一題，楊岳蓁做了一題，張語珊 pA 模擬 subdivision 燒雞然後被我拿來做完了 ( 雖然也貢獻了一次 WA )，接下來陷入一個巨大燒雞 ( 這時候可能才開場一個半小時吧 )，總之是楊岳蓁那題一直 TLE 壓不過，我跟張語珊不會找點點，其他題我沒有深入思考是我的疏失。

而且這場我主要負責看錯題目，比如以為矩形可能是斜的、或點點沒先告訴你，都被張語珊抓到我在亂講，總之要好好看題啦。

最後收在 rk 很後面，打完很擔心會不會進，可能是前面一堆 AI ( ? ) 的關係還是進了。
應該不是女保吧，總覺得兩個 EGOI 國手打團體賽還需要女保有點難看。

檢討 :

  • 跟子樹有關的操作沒想到樹壓平
  • 找點點沒想到可以排序
  • DP 明明都想到最長鏈了但沒有好好想完
  • 沒有去幫楊岳蓁 debug 或是也至少嘗試寫一下

YTP 決賽

我喜歡淺色的衣服，但今年是深色 : (
楊岳蓁好像比較喜歡黑色的。

開場我寫了 Hello，然後就抽到我不會的數學題，莫名其妙吃到 WA 而不是 TLE 後交給楊岳蓁，楊岳蓁同時支援我和張語珊 debug 好強，團隊合作讚。
接下來翻題本找了一個看起來像 hash 的題目，雖然有點久沒寫 hash 但還是有成功寫好，丟上去竟然後面的子題 WA。我以為是 mod $1029000029$ 不好 ( ? )，改了一大堆不同的質數，但都沒有用。

燒雞，但這時楊岳蓁有持續輸出，所以應該沒事，團隊合作讚。
我發現某題超簡單然後很快做掉，接下來繼續 debug 和吃 WA，然後就開始撈子題。

最後收在 rk.10。

我還帶了很多武陵科學班成發的太陽小袋子送給親朋好友，劉芸兆要送我的數奧小袋子也成功透過涓涓抵達 YTP ( 數奧小袋子好可愛 ! )。
最後成功揪了 TGOI 2 ! $9$ 人拍大合照，楊岳蓁要去鬥 code 幫輔導員慶生，但我爸媽不會讓我在台北待那麼久，所以得回家，不過我還是找了陳瑀萱、王禹喬、楊岳蓁和張語珊錄了生日快樂給我學姊 ( 她生日 ! )，雖然說是在廁所對著鏡子錄的，有點奇怪。

檢討 :

  • 相信 hash 的正確性，不要相信自己 case 都有弄好。( TLE 的 blog 也說過 )

NTUCPCPC 決賽

身為桃園人而且我不想太早起床，我 10:00 多才順利抵達德田館，當然楊岳蓁和張語珊早就到了。

開場我跟楊岳蓁分別抽了一個水題，我那題根本跟昨天 YTP 差不多 ( ? )，我打完才知道楊岳蓁那題是我喜歡的 Akari 欸 ! ! ! 太可惜了。

張語珊抽到風車題之後就開始研究，我跟楊岳蓁對非洲大草原 ( 題目名字 ) claim 了一些 small to large merging，由楊岳蓁負責實作，我也不知道為什麼開始噴 RE。
我切去想 pH，發現我之前寫過一題…有點像的題目 ? 但 dijkstra $\mathcal{O}(E \log V)$，我有大概 $3e7$ 條邊和 $1e6$ 個點，而且我要跑 $5$ 次，怎麼想都有點燒雞。

不久楊岳蓁猜到了非洲大草原的梗，然後過了。張語珊繼續想風車然後開始實作。

外面有食物， NTUCPCPC 的提拉米蘇好好吃喔 ! ! ! 我吃了三塊，而且還有水果和蛋糕和奶茶，好好吃。
電腦教室超熱的，我懷疑西曬是罪魁禍首之一，加上旁邊那隊可能佔了 $3.8$ 個位子，壓迫我們的生存空間，所以我有事沒事就假借各種名目跑出去吃東西喝飲料上廁所。

過了有點久都沒什麼進展，我就來實作了 pH，然後我寫超久，也確實拿到 TLE。

楊岳蓁也看了 pH，她想了一下說可以 DP。

楊岳蓁 : 「先往右推，再往下推，再往上推。」

雖然她好像完全不知道我中間的 dijkstra 在幹嘛，但成功省掉四個 $\log$，然而結果還是 TLE。

我想了一下馬上發現我中間那個 dijkstra 完全可以 DP 省掉欸，趕快改，楊岳蓁大概不知道我在幹嘛，所以她問我還剩一個 $\log$ 怎麼壓。

我 : 「沒有了，$\log$ 都被我殺光了 !」

再傳上去果然過了 ! 但是沒氣球，我很難過。
團隊合作讚。

剩大約半小時給張語珊修風車，但我根本不知道她之前怎麼算的，沒幫上忙我很抱歉。

最後開板 rk.9，拿到潛力 star 獎 ( 開板排名上升最多 )。

頒獎時間有點 delay，我爸好像等有點久了不妙，張語珊要回鬥 code 烤肉 ( 這麼好，國手被李忠謀 DQ 了傷心 )，所以就先跑了。
在台大騎腳踏車氣球在後面飛，上次好像是國中的 NPSC 了，格外有趣，也很危險。

然後我還飛奔去找睿睿拿 APIO bronze 跟聽 EGOI 大學燒雞的噩耗。

檢討 :

  • 沒觀察到往右上下走的方格圖可以 DP
  • 喜歡 C-style array，不使用二維 vector ，出現 $nm \leq 1e6$ 時使用噁心 index 導致實作超級慢
  • 承上，所以我覺得有時候還是要用一下二維 vector
  • dijkstra 丟進去沒加負號 debug 很久
  • 不會猜梗 ( ?

不重要小插曲 : 觀賞 IOI 2026

IOI 2026 day1 我正在收要去台南奶奶家的行李，但我每收 $10$ 分鐘就會想偷看一下我的偶像 Daria Perekopska 是不是有拿分，導致效率堪憂。

day2 我在台南美食之旅 ( 對，好好吃喔 )，下午去什麼歷史博物館吹冷氣，因為太熱了，但我好像都在分心觀看記分板，最後 DP 拿到銀牌，還是很強 : D

雖然台灣隊有人打不好的樣子，但我覺得能選上國手然後出國比賽，有盡力比過了就很厲害的，畢竟我的 EGOI day2 表現也是 💩。

成大賽 決賽

暑假的最後一場比賽。
張語珊當天早上坐火車來，楊岳蓁坐車來，我先住在奶奶家。
然後早上下大雨，但大家都準時出現了，好強。

楊岳蓁好像生病了，我原本覺得楊岳蓁感覺很像那種不太生病的超人欸。

開打後我們很快就過了兩題，但因為我不會國中數學導致吃了一個罰時。
接下來我跟楊岳蓁研究 pC，先因為我打錯等號吃了一個罰時，然後再因為我們的數學 WA 的又吃兩個罰時 ( 對，現在已經吃四個了 )。
實在有點恐怖，所以我跟張語珊就先下去吃午餐了 ( 披薩和炸雞 )。

回來楊岳蓁正在實作感覺像大暴力的 pF，我跟張語珊想 pB ( 板上已經有一兩隊做出來了 )，但我有點太笨一直想要大暴力，不久楊岳蓁搶到 pF 首殺 w(ﾟДﾟ)w
然後我又繼續想不到 ( ? )，封板後我跟張語珊亂傳了一個超唬爛的東西又吃了一次罰時，楊岳蓁應該是看不下去了把 pB 拿去做，剛好在結束前做出來，我們的名次看起來很有希望。

ㄜ楊岳蓁在做 pB 的時候我好像在跟張語珊聊天，問北一女科學班去台大修哪個微積分。

開板之後從 rk.4 升到 rk.3，有 $2000$ 元的獎金。
拿到好多氣球喔，我喜歡氣球 ! ! !

楊岳蓁生病是不是會變很強啊，EGOI 不要生病喔。

檢討 :

  • 數學不先檢查一下再送
  • 兩條式子沒有判算出來的東西是不是一樣
  • 一直想要亂暴力沒有好好觀察性質，其實有「刪掉之後餘數不變」的性質，之後就可以很快推出答案
  • 忘記帶吉祥物

反思

個人貢獻 ?

我好像打團體賽比較像在打個人賽，就是我寫我的，隊友寫他的，分數聯集，當然我會盡量把全部會做的東西做掉，這樣團體表現很差也可以說我個人貢獻很多題。但這樣團體表現很差我也會生氣，覺得隊友沒做事。我小時候好像會很生氣的說「整場都是我打的」之類的，不過國中的時候也沒辦法啊，學校就這幾個人會寫程式。

經過這麼多比賽之後我覺得好像心態有變不太一樣，也有點說不太出來，可能有變比較不在意個人貢獻度了，雖然有可能是因為我也沒什麼大貢獻什麼導致 NTUCPCPC 差點沒晉級。

當然也有可能是因為楊岳蓁很棒，我燒雞她都會順利救場。但什麼都沒做的時候還是會有點罪惡感 ( ? )，像是成大決賽我都想不到怎麼好好做 pB，楊岳蓁不僅做出來了還搶到另一題首殺，超級強的。說不定楊岳蓁現在覺得我都在躺分然後很生氣。

好吧我也有聽說團體賽就是這樣的比賽，大家把想法聯集一下可能就 AC，優缺點互補也是重要的一環，只是我以往不常享受團體賽因此不太習慣 ( ? )，但不得不說這個暑假都玩得很開心。

溝通

雖然說團體賽重點之一就是組內溝通協調啊，但我以前幾乎不和隊友溝通 ( ? ) 的樣子，我印象中也沒有因為溝通而多解出一道題過。

但今年感覺又不太一樣了，我跟楊岳蓁算是合作 ( ? ) 寫出 NTUCPCPC 決賽 pH，感覺很酷耶。然後我的感覺是，都是楊岳蓁在幫我忙，讓我可以做出東西或避免 WA/TLE，但我好像沒什麼幫到其他人 debug 之類的。有可能是因為打比賽一路上都是一個人，沒什麼跟別人討論的經驗 ? 導致我不太會跟別人討論，總之我要檢討我的團隊合作能力。

隊友

我覺得楊岳蓁很棒喔，然後張語珊數學也好好 ( 台大風車題我看一眼就丟了吧抱歉 )，而且都很好相處。

而且楊岳蓁和張語珊說我可以把氣球全都帶回家耶 ! 超級好的 ! 氣球 !

表現

今年的表現會比去年好其實也是意料之中，因為我是國手經過一年的成長了嘛。

但我覺得因素也不止這個…可能是隊友很強吧，或是配合比較好 ?

或者是隨著年紀增長我越來越覺得這種團體賽要當樂趣，然後不要太看重名次，不然會不好玩。
希望我 EGOI 也能多多這樣想吧…但還是好想拿金牌喔。

結尾

我在打的時候一直在想我要打 yyc 還是 楊岳蓁，或是歪歪西，打張語珊的名字都沒有這個困擾。

然後在選訓的時候原本說要跟涓涓一起打，但普台的老師說她要跟普台的打，可能是因為我太菜了。
