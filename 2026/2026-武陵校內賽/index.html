2026 武陵校內賽
Sep 8, 2026

今天 9/8 是武陵的校內賽，因為在下午，直接跟台大微積分第一堂課撞爛了 > <

還有悲報，我從起床開始發現喉嚨有點痛，然後喉嚨就開始越來越痛，原本早上想 vir 個 ABC 練練手感結果不得不去休息 ( 我們班後面的巧拼城堡好讚 ) ，不然下午可能就沒力氣比賽了，反正我覺得 ABC 不打也還好。

然後我整個早上都超怕待會會打一打暈倒，然後沒有第一名，一定很尷尬。
今天特別注意題目要看兩次、多驗解、慢慢寫，然後不要暈倒。

比賽

題目。

然後今年也很感人的是蕭凱鴻和宋睿軒出題目，不是武陵的老師弄的恐怖 zerojudge 水題大賽 ( 高一打到怕了 )。
而且是用 CMS 打，題本和子題也都很精緻喔 ( 愛心 )。

可以開始測環境，只有 codeblocks 和 devc++，我用 codeblocks，發現 <bits/stdc++.h> 不能用，拉完了。
而且編譯要 $20$ 秒，拉完了。

監考老師說他也沒辦法，你們就自求多福吧。

0/0/100/100/0/100/0。
寫完三個水題，完成簽到，喉嚨超痛的。

0:25
pB nim 感覺是 CSES Nim Game II，但我忘光他在幹嘛了。
拿到 $0$ 分，為什麼我連一堆石頭都不會做啊，燒雞。
大致把每題都看過，因為頭有點暈所以 pA DP 先跳，去寫 pG。

0:55
0/0/100/100/0/100/50。

改成 priority_queue 之後還是 TLE。

1:20
0/0/100/100/0/100/100。
算一下點有快 $2e5 \times 10$ 個，邊有 $2e5 \times 18$ 條，有點多難怪燒雞。

猜對 tuple 的標頭檔很不意外的是 <tuple>。
砸 set 再次 TLE，改 priority_queue 之後先因為本地不能測試吃到 WA，改一下就過了。

去上廁所和喝水，然後我覺得我的喉嚨每況愈下了，超級痛。

檢討

  1. pA 拿子題驗解，讚。
  2. pB 不會 nim ，檢討 ( 雖然他不在 IOI syllabus 內啦 )。
  3. pE 爆破數學式的能力有待加強，感覺這種算數列的用前一項推滿不錯的 ( DP )。
  4. pE 不要想亂砸東西，先好好觀察。
  5. pG 壓過了，讚。
