感染シミュレーション - 題解
Oct 29, 2026

前言

因為 TLE 說他生病了，希望我沒有被傳染，然後我就想到我去年忘記補這題了 ( °□°)

順便我想在 10/29 寫一個 blog。

題目

JOIG 2024 初選的最後一題，JOIG 就是日本版的 TGOI，AtCoder 上面有日文的題目。

以下是中文 :

ㄟ狗蟻 ( EGOI ) 餐廳有 $N$ 個客人，第 $i$ 位客人在 $[ L_i, R_i )$ 時間內在餐廳裡面。有 $Q$ 筆詢問，問如果第 $p_i$ 位客人生病，且病毒感染強度是 $x_i$ ( 病毒感染強度 $x$ 代表說，如果一個生病的人跟一個健康的人同時待在餐廳裡的時間 $\geq x$，健康的人就會被傳染 ) ，問會導致多少人生病 ?
$N, Q \leq 1e5$
$1 \leq x_i, l_i, r_i \leq 1e9$

題解

題解

待會變數都會用小寫，然後用陣列那樣的符號，像是 $l[i]$。

先觀察一下子題 : $Q \leq 5$ ，也就是說每次都可以直接模擬，觀察到店內有生病的人的時間會構成一個連續的區間，病毒不可能消失一段時間之後突然又出現嘛。而且，如果第 $i$ 個人要傳染給第 $j$ 個人 ( 並且滿足 $r[j] > r[i]$，才能延長有病人的時間區間 )，必須滿足 $r[i] - l[j] \geq x$。

現在想要快速算出對於每個詢問，店內有病人的時間區間右界是多少 ( 我覺得是這題最酷的部分 )。

再觀察一下子題，subtask 7 說保證「$L_1<L_2<…<L_n$ 且 $R_1<R_2<…<R_n$」，也就是說會長這樣 :

那可以對於每個人 $i$，計算「比 $i$ 晚離開餐廳的人之中，最早進來餐廳的人的 $l[j]$ 是多少」，然後令 $cnt=r[i]-l[j]$，就會知道第 $i$ 位客人可以跟比他晚離開的某個人接觸多長的時間 ( 不過在這個子題的限制下，比 $i$ 晚離開又跟他相處最久的人一定是 $i+1$ )。

對於每個詢問，假設一開始生病的是第 $i$ 個客人，想要算出店內有病人的時間區間 $[l[i], t[i])$，會發現 $t[i]$ 就是所有比 $i$ 號客人還晚離開且 $cnt<x[i]$ 的人之中最早離開的人離開的時間 ( $t[i] = \min \lbrace r[j] \mid r[j] \geq r[i] \text{ and } \text{cnt} < x \rbrace$ )，也就是找到病毒第一個傳染不出去的地方。

假設一開始生病的是粉紅色那個人，粉色和黃色接觸時間有 $\geq x$、黃色和綠色接觸時間有 $\geq x$，但綠色和黑色接觸時間 $< x$，那麼這個病毒最晚只會存活到綠色的人走出店的那一刻，這就是要算的 $t$。

實作算 $t[i] = \min \lbrace r[j] \mid r[j] \geq r[i] \text{ and } \text{cnt} < x \rbrace$ 的部分，可以把所有人先按照 $r$ 由大到小排序，依序算出 $cnt$ 並丟進一個單調 stack，再搭配二分搜就可以算出來了。

接下來看如果沒有保證「$L_1<L_2<…<L_n$ 且 $R_1<R_2<…<R_n$」，要怎麼算。
其實完全可以沿用上面的方法，只是可能會有這種 case :

會發現黃色那個人的 $cnt$ 已經超出他在店裡的總時間了耶，但是沒關係，因為粉紅色的人還是可以傳染給綠色的人 ( 而且要算的是「店內存在病人的時間區間」，不是「這個區間裡出現的每個人都有被傳染到」 )，所以這種 case 就把 $cnt$ 當一種過度狀態，就可以沿用上面的方法算出 $t[i]$。

現在算出所有的 $[l[i], t[i])$ 了。

如果 $j$ 這個人會被 $i$ 傳染，那必須滿足 :

  1. $r[j]-l[j] \geq x[i]$，也就是說他必須在店裡待至少 $x[i]$ 單位的時間
  2. $r[j]$ 在 $[l[j]+x[i], t[i]]$ 這個區間內，這樣他才會被傳染到

1. 的部分可以把詢問離線，按照 $x[i]$ sort 一下，也把客人按照 $r[j]-l[j]$ sort 一下，就可以用雙指針維護符合 $r[j]-l[j] \geq x[i]$ 的客人有哪些了。
2. 的部分可以把符合 1. 條件的客人的 $r[j]$ 丟進一個 BIT，數值值域很大所以要離散化。

複雜度大概是 $\mathcal{O}( (N+Q) \log N )$ ，這樣就算完了。

我的實作

以下的實作大概是按照這個步驟 :

  1. 把客人按照 { $r$ 大，$l$ } 小排序。
  2. 把詢問按照 $r$ 由大到小排序。
  3. 算 $cnt$ 並用一個單調的 stack 維護，搭配雙指針算出對於每個詢問，店內有病人的時間區間右界 $t$。
  4. 把客人按照 { $r-l$ 大，index } 排序。
  5. 把詢問按照 { $x$ 大， index } 排序。
  6. 用雙指針搭配 BIT 算出答案。
